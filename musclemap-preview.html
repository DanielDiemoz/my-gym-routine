Screenshots

Features

Two Looks
Flat vector silhouette OR photorealistic body with colored muscles on top
Left/Right
Each muscle surface individually addressable (e.g. HAMSTRINGS_LEFT)
Region Views
Full body, upper body, lower body — real cropped views, not zoom
Color Models
Load, Frequency, Balance, Recovery Risk
Monochrome
Single brand color: grey → your color (0–100)
Sex
Male + Female bodies included
Glow + Tooltips
Per-muscle gradient shading, glow halo, hover/tap tooltips
Headless Core
UI-free core usable from any framework (React, Vue, Svelte...)

Code Example

import { MuscleMap } from "@musclemap/react";
import type { MuscleMapValues } from "@musclemap/core";

const values: MuscleMapValues = {
  CHEST:     { score: 88 },
  LATS:      { score: 84 },
  QUADS:     { score: 66 },
  CALVES:    { score: 26 },
  DELTOIDS:  { score: 72 },
  BICEPS:    { score: 80 },
  TRICEPS:   { score: 75 },
  ABS:       { score: 60 },
};

<MuscleMap
  values={values}
  view="BOTH"
  sex="MALE"
  colorModel="LOAD"
  monochromeColor="#7c3aed"  // oppure usa colorModel
  glow={true}
  showLegend={true}
/>
